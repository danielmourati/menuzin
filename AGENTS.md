- Order scheduling slots are generated by one shared pure helper (src/lib/scheduling.ts, fixed São Paulo time) used by both the checkout and server validation — keeps client slots and server checks identical.
- Kitchen ticket layout is built through `buildKitchenTicketForPrinter`; automatic printing may honor per-printer duplicate copies, while manual reprints always print one copy — prevents layout drift and accidental duplicate reprints.
- AI order agent: the model only picks catalog IDs via the update_draft tool; prices, fees, coupons and change are recomputed server-side in src/lib/ai-agent.server.ts and the order is created only by the customer's confirm button through createOrder — prevents the model from setting prices or placing orders.
